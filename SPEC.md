# OSS Radar v1 spec (ossradar.net, owner Yash Patil, GitHub yvshpvtil)
Daily tracker of fastest-rising open-source AI & developer-tool GitHub repos, ranked by star velocity (stars gained last 24h / 7d), each with a one-line "what it does and why it matters". Monetized via sponsorships (site sponsor bar + newsletter slot; launch price $99/week rising $25 per sale) and later featured listings. Audience: developers.

Build in THIS directory (it is the repo root):
- Next.js latest (App Router, TypeScript, Tailwind), static/ISR friendly for Vercel free tier. Clean, fast, dark/light toggle (respect system), mobile friendly. SEO: metadata per page, OG images (next/og ImageResponse), app/sitemap.ts, app/robots.ts, RSS feed at /rss.xml (route handler, static).
- Pages: home leaderboard (today / this week toggle, category filters: AI agents, LLM tooling, MCP, coding agents, RAG/vector, local LLMs, devops, other); /repo/[owner]/[name] (generateStaticParams) with stars, delta, language, description, one-liner, inline SVG star-history sparkline, similar repos; /category/[slug] pages; /sponsor explaining slots and pricing (payment link placeholder clearly marked TODO); /about; newsletter signup form posting to /api/subscribe which saves to a JSON file/placeholder via a small storage adapter interface easy to swap for Beehiiv (note Vercel FS is read-only: log + return ok in that case); a visible <SponsorSlot> component with placeholder "Your product here, sponsor OSS Radar" linking to /sponsor.
- Data pipeline: scripts/collect.ts (run with `npx tsx`, npm script `collect`) using GitHub Search API with GITHUB_TOKEN env (or `gh auth token` fallback): repos created in last ~90 days matching AI/devtools topics/keywords (llm, ai-agents, mcp, rag, vector-database, local-llm, coding-agent, devops, etc.), plus recently pushed popular repos. Respect rate limits, dedupe, cap ~300-500 repos. Writes data/snapshots/YYYY-MM-DD.json (full_name -> stars) and data/repos.json (metadata + computed delta24h, delta7d, velocityEstimated flag, category, oneLiner, history array). Deltas come from prior snapshots; when no prior snapshot exists use stars/age-in-days estimate and set estimated=true, and the UI must label these honestly ("est." badge + note). Categorize by topics/keywords. One-liner: template from description now, with a pluggable summarize() hook (e.g. scripts/summarize.ts, uses LLM if OPENAI_API_KEY/ANTHROPIC_API_KEY set later, else template). Site reads data/repos.json at build time.
- .github/workflows/daily.yml: cron '30 2 * * *' + workflow_dispatch, permissions contents: write, runs collect with GITHUB_TOKEN, commits data if changed (which triggers Vercel redeploy).
- README.md describing project, data job, local dev, TODOs (Vercel deploy, DNS from Namecheap, newsletter provider, payment link).
- Must pass `npm run build` and `npm run lint` cleanly. Don't deploy, don't sign up for anything.
